## 📖 نظرة عامة

تطبيق **طبيبي الذكي (SmartMedic)** هو منصة طبية شخصية شاملة لنظام أندرويد تساعد المستخدمين على تنظيم نتائج تحاليلهم المخبرية، متابعة قراءاتهم الحيوية اليومية (سكر الدم، ضغط الدم، الوزن ومؤشر كتلة الجسم)، ضبط مواعيد الأدوية بمنبهات دقيقة متوافقة مع **أندرويد 12 حتى 16+**، مسح تقارير المختبرات والوصفات الطبية (الروشتات) بالذكاء الاصطناعي، والحصول على استشارات ذكية عبر **Firebase AI Logic** مع **تسجيل الدخول بحساب Google** ودون الحاجة لتضمين أي مفتاح API خاص داخل البرنامج.

## ✨ المميزات الرئيسية

### 1. 🔐 تسجيل الدخول بحساب Google وحماية Firebase AI (بدون مفاتيح API)
- **المصادقة عبر حساب Google**: يعتمد التطبيق على **Jetpack Credential Manager** (`GetSignInWithGoogleOption`) والدخول التلقائي السريع (`GetGoogleIdOption`) المرتبط بـ **Firebase Authentication**.
- **بوابة مصادقة آمنة**: يتم حماية الشاشات الرئيسية وخدمات الذكاء الاصطناعي خلف شاشة تسجيل الدخول، مع عرض الحساب المتصل وإمكانية تسجيل الخروج بسهولة من شاشة **الملف الشخصي والإعدادات**.
- **Firebase App Check**: تهيئة تلقائية في بداية `MainActivity.onCreate()` باستخدام `DebugAppCheckProviderFactory` في وضع التصحيح و `RecaptchaAppCheckProviderFactory` في وضع الإصدار.
- **لا يتطلب مفتاح `GEMINI_API_KEY`**: جميع طلبات الذكاء الاصطناعي (`gemini-3.8-flash`) تمر بأمان عبر **`Firebase.ai`** دون تخزين أي مفاتيح API في التطبيق.

### 2. 🤖 المستشار الطبي الذكي والمحادثة الفورية (`AiAdvisorScreen`)
- **تقرير طبي شامل منظم (`Schema.obj`)**: يحلل الذكاء الاصطناعي جميع بيانات المريض بدقة ويشمل:
  - نتائج التحاليل المخبرية والقيم المرتفعة والمنخفضة
  - قراءات ضغط الدم وسكر الدم الأخيرة
  - الوزن ومؤشر كتلة الجسم (BMI) والأمراض المزمنة
  - الأدوية النشطة والتداخلات الدوائية والغذائية (الأطعمة الواجب تناولها أو تجنبها)
- **محادثة طبية ببث فوري (Streaming Chat)**: استخدام `generateContentStream()` لعرض الردود الطبية والغذائية بشكل فوري وسلس.
- **شفافية الأخطاء**: عرض تنبيه واضح عند حدوث مهلة زمنية (60 ثانية) أو خطأ اتصال مع زر إعادة المحاولة.

### 3. 📄 استخراج الفحوصات والوصفات الطبية بالذكاء الاصطناعي (Multimodal AI)
- **ماسح تقارير المختبر (`UploadLabReportDialog`)**:
  - يدعم ملفات **PDF متعددة الصفحات** وصور الكاميرا والمعرض (ضمن حد أمان أقل من 20 ميجابايت).
  - يستخرج اسم الفحص، النتيجة، الوحدة، المعدل الطبيعي، التصنيف، اسم المختبر، والتاريخ آلياً.
- **ماسح الوصفة الطبية / الروشتة (`UploadPrescriptionDialog`)**:
  - قراءة الوصفات المطبوعة أو المكتوبة بخط اليد عبر الكاميرا أو المعرض أو PDF.
  - استخراج الأدوية، الجرعة، تعليمات الأكل، التكرار، وقت التنبيه، المادة الفعالة، دواعي الاستعمال، الأعراض الجانبية، والتداخلات الغذائية—مع حفظها وتفعيل منبهاتها بضغطة واحدة.

### 4. 🏠 الصفحة الرئيسية الذكية (`HomeScreen`)
- **مبدّل القياس الحيوي الفردي**: إمكانية الاختيار السريع بين عرض بطاقة **سكر الدم** أو **ضغط الدم** أو **الوزن و BMI** بشكل مستقل وواضح (خيار واحد في كل مرة).
- **تسجيل سريع للقراءات**: نوافذ مباشرة لإضافة قراءات السكر (صائم / بعد الأكل / عشوائي)، الضغط (الانقباضي / الانبساطي / النبض / الفترة)، والوزن مع حساب BMI تلقائياً.
- **تنبيهات الفحوصات الحرجة**: إبراز النتائج غير الطبيعية مع أزرار اختصار للمستشار الذكي ورفع التحاليل والوصفات.

### 5. 💊 المتابعة اليومية ومنبهات الأدوية لأندرويد 12+ (`DailyTrackingScreen`)
- **محرك منبهات دقيق (`MedicationReminderScheduler` و `MedicationAlarmReceiver`)**:
  - يعتمد على `AlarmManager.setExactAndAllowWhileIdle` / `setAlarmClock` لضمان عمل التنبيه في وقته الدقيق حتى في وضع السكون.
  - دعم كامل لنظام **أندرويد 12+** (`SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM`) و **أندرويد 13+** (`POST_NOTIFICATIONS`) مع بطاقة حالة وتوجيه لطلب الأذونات.
  - دعم **التنبيهات الفورية ملء الشاشة**، الصوت والاهتزاز، إعادة جدولة المنبهات تلقائياً بعد إعادة تشغيل الهاتف (`BootCompletedReceiver`)، وخيار استثناء تحسين البطارية.
- **بطاقات الدواء التفاعلية**: عرض المادة الفعالة، الاستخدامات، الأعراض الجانبية، والتداخلات الغذائية، مع زر تسجيل **تم التناول اليوم** وتجربة التنبيه فوراً.

### 6. 🧪 إدارة الفحوصات المخبرية و 📊 السجلات وتصدير PDF
- البحث والفلترة (`الكل` / `غير طبيعي` / `طبيعي`) وإضافة أسماء تحاليل مخصصة.
- عرض تاريخ القياسات والرسوم البيانية للسكر والضغط والوزن.
- تصدير تقرير طبي بصيغة **PDF** جاهز للطباعة أو المشاركة مع الطبيب (`PdfReportExporter`).

### 7. ⚙️ التصميم المتجاوب، الوضع الليلي، اللغات، والنسخ الاحتياطي
- **تناسق كامل للوضع الفاتح والداكن (Light & Dark Mode)**: تباين ألوان مدروس على جميع الشاشات والنوافذ وبطاقات التحليل الدوائي (`android:forceDarkAllowed="false"`).
- **تعدد اللغات والاتجاه (RTL / LTR)**: دعم فوري للغة الجهاز التلقائية، **العربية (من اليمين لليسار)**، **الإنجليزية**، و **الروسية**.
- **النسخ الاحتياطي والاستعادة (`GoogleDriveBackupManager`)**: تصدير كافة البيانات بصيغة JSON إلى Google Drive أو الذاكرة المحلية، واستعادتها بوضع **الدمج** أو **الاستبدال**.

## 🛠️ التقنيات المستخدمة والبنية البرمجية

| الطبقة | التقنية المعتمدة |
| :--- | :--- |
| **لغة البرمجة** | Kotlin `2.2.10` |
| **واجهة المستخدم** | Jetpack Compose (BOM `2024.09.00`) + Material Design 3 |

## 📦 بناء وتصدير ملف APK

### الطريقة الأولى: البناء المباشر عبر Gradle
من المجلد الرئيسي للمشروع:

```bash
gradle assembleDebug
```

سيتم إنشاء وتصدير ملف الـ APK في المسار التالي:
```text
app/build/outputs/apk/debug/app-debug.apk
```

### الطريقة الثانية: التصدير من قائمة AI Studio
1. افتح قائمة **الإعدادات / التصدير (Settings / Export)** داخل Google AI Studio.
2. اختر **Generate APK / AAB** لتحميل ملف التثبيت مباشرة على جهازك أو مشاركته.
3. لإصدار نسخة Release موقّعة يدوياً، ضع متغيرات البيئة (`KEYSTORE_PATH`، `STORE_PASSWORD`، `KEY_PASSWORD`) ونفّذ:
   ```bash
   gradle assembleRelease
   ```
